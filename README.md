# SmartScrape AI 🚀

**A ready-to-use web scraping workspace** for creating, managing,
scheduling, Automated and reviewing scraping jobs from one clean interface.

## ✨ Features

-   Create and run scraping jobs from a simple web UI
-   Save and manage targets in **Scrape Jobs**
-   Schedule recurring jobs (manual, interval-based, hourly, or daily)
-   Preview results, images, and available video links
-   Export results to **CSV** or **JSON**
-   View run status and recent results
-   Responsive dark UI with selected-job highlighting

## 🧰 Tech Stack

-   **Frontend:** React, Vite
-   **Backend:** Python, Django REST Framework
-   **Scheduling:** Background scheduler service
-   **Data exchange:** REST API, JSON, CSV

## ⚙️ Getting Started

1.  Clone the repository:

    ``` bash
    git clone https://github.com/hemantkarne70-tech/SmartScrape-AI.git
    cd SmartScrape-AI
    ```

2.  Follow the setup instructions in the project folders and configure
    the required environment variables.

3.  Start the backend and frontend using the project's setup
    instructions.

4.  For scheduled jobs, start the scheduler service as described in the
    project README/setup files. The scheduler must remain running for
    automatic execution.

> **Note:** Scraping availability depends on the target website, its
> access rules, and the scraper configuration. Always respect applicable
> laws, website terms, and robots.txt policies. Do not use this project
> to access private data or bypass access controls.
